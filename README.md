# Policememos Tap

## How do I install these formulae?

`brew install policememos/tap/<formula>`

Or `brew tap policememos/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "policememos/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
